# MoonlitBot downloads

[MoonlitBot](https://moonlitbot.onrender.com) is a free AI teammate: hand it a task, and it researches, writes and builds in the background, then hands you real files. This page holds the downloads. MoonlitBot is made by Sunovo Labs.

## MoonlitBot for Windows

**[Download MoonlitBot-Setup.exe](https://github.com/FlakeSap/moonlitbot-downloads/releases/latest/download/MoonlitBot-Setup.exe)**
(version 1.0.0, about 107 MB, Windows 10 and 11, 64-bit)

- The installer lets you choose where MoonlitBot is installed.
- The app is MoonlitBot in its own window with its own icon. It opens the live site, so you always get the newest MoonlitBot, and it needs an internet connection, like the website.
- **It updates itself.** The app checks for a newer version in the background and installs it when you close it, so you never need to download it again.
- **Windows may warn "unknown publisher" or "Windows protected your PC"**, because the app isn't code-signed yet (a signing certificate costs money). Choose **More info**, then **Run anyway**.
- **Sign in with Google** (optional) opens your normal browser, because Google doesn't allow sign-in inside an app's own window. When it says you're signed in, go back to the app.
- Talking to MoonlitBot with your voice isn't available in the Windows app. Use the website in Edge or Chrome for that.
- To remove it, use Windows Settings, then Apps, then MoonlitBot, then Uninstall.

Each release also holds `latest.yml` and `MoonlitBot-Setup.exe.blockmap`. The app reads those to update itself; you do not need to download them.
